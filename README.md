## 陳孟蓉 Meng-Rong Chen

國立中央大學 資訊工程學系

研究興趣在**可解釋且穩健的多模態 AI**——特別是 AI 生成內容與假新聞偵測，以及生成式 AI 帶來的資安風險。目前的大學專題以概念瓶頸模型（Concept Bottleneck Model）讓影像端的 AI 生成痕跡偵測可被解釋，希望進一步研究模型在因果可靠性與對抗攻擊下的穩健性。

---

### 研究與專題

**[TC-MultiDetectron — 具高度可解釋性之繁體中文多模態假新聞檢測系統](https://github.com/MengRong8/TC-multidetectron)**　`大學專題｜指導教授：楊鎮華`
負責影像端模組：以 OWL-v2 擷取影像中的物件區域，再以概念瓶頸模型偵測 AI 生成痕跡，讓判斷結果能對應到人可理解的概念；並參與設計跨模態融合層。

**[APEX — 生成式 AI 釣魚郵件與 Prompt Injection 混合式安全閘道](https://github.com/MengRong8/IT_Risk)**　`Python・LLM・Docker`
規則式優先、語意模糊再升級給 LLM 的混合式偵測器：整體準確率 90%、釣魚召回率 85%，只有 20% 樣本需呼叫外部 API，延遲約為純 LLM 的 15%。我負責 Prompt Injection Lab、Docker 環境與 Dashboard。

**[SafeBuddy — 防身警報裝置與求助聯動系統](https://github.com/MengRong8/safebuddy)**　`ESP32・Flutter・Node.js`　🥉 計算機網路應用創意競賽 銅牌獎
ESP32 警報按鈕經藍牙／Wi-Fi 連動 App，自動以簡訊傳送求助位置；並以 DBSCAN 分析約 9 萬筆交通事故資料，產生危險區域熱區。

**[Hermes Agent 可驗證技能](https://github.com/Netdb-NCKU/final-project-MengRong8)**　`AIASE 2026`
為 Hermes Agent 設計四項可驗證技能：Text-to-SQL、程式撰寫與除錯配對、開放式等價性檢查。

**[gem5 + NVMain 三層快取模擬](https://github.com/MengRong8/gem5_nvmain_HW)**　`計算機組織`
在 gem5 加入 L3 Cache，搭配 NVMain 模擬 PCM 主記憶體，分析快取設計對 NVM 寫入的影響。
